# GolDay Website

A publish-ready static website for GolDay, designed for GitHub Pages deployment.

## Files
- `index.html` and `golgunu.html` — main landing pages
- `robots.txt` and `sitemap.xml` — basic SEO files
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow

## Deployment
1. Open the repository Settings > Pages.
2. Choose "GitHub Actions" as the source.
3. Push changes to the `main` branch to trigger deployment.

Once Pages is enabled, the site will be available at:
https://vecdi-yalcin.github.io/goal.day-website/
